n8n 基礎教學：入門指南

本教學將幫助您了解 n8n 的基本概念、界面操作和簡單工作流的創建。無論您是自動化新手還是有經驗的開發者，這份指南都能幫助您快速上手 n8n，開始創建您的第一個自動化工作流。

n8n 簡介

n8n（發音為 "n-eight-n"）是一個開源的工作流自動化平台，它允許您連接不同的應用程式和服務，並在它們之間自動化數據流動和任務執行。

主要特點

  • 開源免費：基本功能完全免費，可以自行部署
  • 圖形化界面：直觀的拖拉式界面，無需編程即可創建複雜工作流
  • 豐富的整合：支援 400+ 種第三方服務和應用
  • 靈活可擴展：支援自定義 JavaScript 代碼和函數
  • 原生 AI 功能：內建 AI 功能，可輕鬆整合各種 LLM 模型

與其他工具的比較

相比其他自動化工具（如 Zapier、IFTTT、Integromat 等），n8n 的主要優勢在於：

  • 完全控制：自託管意味著您擁有數據和流程的完全控制權
  • 無限制工作流：沒有工作流數量或執行次數的限制
  • 高度自定義：可以使用 JavaScript 進行深度自定義
  • 隱私保護：敏感數據不會離開您的基礎設施
  • 社區支持：活躍的開源社區和持續更新

安裝和部署 n8n

n8n 提供多種安裝和部署方式，您可以根據自己的需求選擇最適合的方法：

使用 Docker 安裝（推薦）

docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

使用 NPM 安裝

npm install n8n -g
n8n start

使用桌面應用

n8n 也提供了桌面應用版本，您可以從 官方網站 下載適合您操作系統的版本。

雲端服務

如果您不想自行部署，也可以使用 n8n 提供的雲端服務 n8n.cloud。

基本概念

在開始使用 n8n 之前，了解以下基本概念將幫助您更好地理解 n8n 的工作原理：

工作流 (Workflow)

工作流是 n8n 中的核心概念，由多個節點組成，形成一個完整的自動化流程。每個工作流都有一個唯一的 ID 和名稱，可以手動觸發或設置自動觸發。

節點 (Node)

節點是工作流中的基本構建單元，每個節點代表一個特定的操作或服務。n8n 提供了豐富的內置節點，涵蓋了各種常見服務和功能。

節點類型包括：

  • 觸發節點 (Trigger Nodes)：啟動工作流的節點，如定時觸發、Webhook 等
  • 常規節點 (Regular Nodes)：執行特定操作的節點，如 HTTP 請求、數據處理等
  • 核心節點 (Core Nodes)：n8n 內置的基本功能節點
  • 社區節點 (Community Nodes)：由社區開發的擴展節點

連線 (Connection)

連線表示節點之間的關係，定義了數據如何從一個節點流向另一個節點。在 n8n 的界面中，連線以線條的形式顯示。

執行 (Execution)

執行是工作流的運行過程，按照節點之間的連線順序依次執行。每次執行都會生成一個執行記錄，包含執行時間、狀態和結果。

憑證 (Credentials)

憑證用於安全地存儲連接外部服務所需的認證信息，如 API 密鑰、用戶名和密碼等。n8n 會加密存儲這些敏感信息。

界面導覽

n8n 提供了直觀的用戶界面，讓您可以輕鬆創建和管理工作流。以下是主要界面元素的介紹：

工作流列表

工作流列表顯示了所有已創建的工作流，您可以在這裡創建新工作流、搜索現有工作流、查看工作流狀態等。

工作流編輯器

工作流編輯器是您創建和編輯工作流的主要界面，包含以下部分：

  • 畫布：拖放和連接節點的區域
  • 節點面板：顯示所有可用的節點
  • 節點設置面板：配置選中節點的參數
  • 執行面板：顯示工作流執行結果

節點面板

節點面板列出了所有可用的節點，按類別分組。您可以使用搜索框快速找到需要的節點，然後將其拖到畫布上。

執行面板

執行面板顯示工作流的執行結果，包括每個節點的輸入和輸出數據。這對於調試和優化工作流非常有用。

設置面板

設置面板允許您配置 n8n 的全局設置，如 API 密鑰、數據庫連接、日誌級別等。

創建第一個工作流

讓我們通過一個簡單的例子來創建您的第一個 n8n 工作流。這個工作流將定期獲取一個笑話，並通過電子郵件發送。

步驟 1：創建新工作流

  1. 點擊工作流列表頁面上的「+ 新工作流」按鈕
  2. 輸入工作流名稱，如「每日笑話」
  3. 點擊「創建」按鈕

步驟 2：添加觸發節點

  1. 在節點面板中搜索「Schedule」
  2. 將 Schedule 節點拖到畫布上
  3. 在節點設置面板中，選擇「每天」模式
  4. 設置時間為您希望接收笑話的時間，如上午 9:00

步驟 3：添加 HTTP Request 節點

  1. 在節點面板中搜索「HTTP Request」
  2. 將 HTTP Request 節點拖到畫布上
  3. 連接 Schedule 節點到 HTTP Request 節點
  4. 在節點設置面板中，設置以下參數：
    • 方法：GET
    • URL：https://official-joke-api.appspot.com/random_joke
    • 響應格式：JSON

步驟 4：添加 Function 節點

  1. 在節點面板中搜索「Function」
  2. 將 Function 節點拖到畫布上
  3. 連接 HTTP Request 節點到 Function 節點
  4. 在節點設置面板中，添加以下代碼：
// 格式化笑話
return items.map(item => {
  const joke = item.json;
  return {
    json: {
      subject: "每日笑話",
      text: `問題：${joke.setup}\n\n答案：${joke.punchline}`
    }
  };
});

步驟 5：添加 Send Email 節點

  1. 在節點面板中搜索「Send Email」
  2. 將 Send Email 節點拖到畫布上
  3. 連接 Function 節點到 Send Email 節點
  4. 在節點設置面板中，設置以下參數：
    • 收件人：您的電子郵件地址
    • 主題：使用表達式 {{$json.subject}}
    • 內容：使用表達式 {{$json.text}}
  5. 點擊「添加憑證」按鈕，設置您的電子郵件服務器信息

步驟 6：保存和激活工作流

  1. 點擊工具欄上的「保存」按鈕
  2. 點擊工作流名稱旁的開關，將其設置為「活動」

恭喜！您已經創建了第一個 n8n 工作流。這個工作流將在每天指定時間獲取一個笑話，並通過電子郵件發送給您。

常用基礎節點介紹

n8n 提供了豐富的內置節點，以下是一些最常用的基礎節點：

觸發節點

  • Schedule：按照設定的時間表定期觸發工作流
  • Webhook：通過 HTTP 請求觸發工作流
  • Cron：使用 Cron 表達式設置複雜的時間觸發規則
  • Manual：手動觸發工作流

核心節點

  • HTTP Request：發送 HTTP 請求到外部 API
  • Function：使用 JavaScript 代碼處理數據
  • Set：設置或修改數據項的值
  • IF：根據條件執行不同的分支
  • Switch：根據多個條件執行不同的分支
  • Merge：合併來自多個節點的數據
  • Split In Batches：將數據分批處理

服務節點

  • Send Email：發送電子郵件
  • Telegram：發送 Telegram 消息
  • Slack：發送 Slack 消息
  • Google Sheets：讀取和寫入 Google 表格
  • Airtable：讀取和寫入 Airtable 數據
  • Notion：讀取和寫入 Notion 數據

文件節點

  • Read Binary File：讀取二進制文件
  • Write Binary File：寫入二進制文件
  • Read PDF：讀取 PDF 文件內容
  • Spreadsheet File：處理電子表格文件

基礎實戰練習

以下是一些基礎實戰練習，幫助您鞏固所學知識：

練習 1：定時天氣通知

創建一個工作流，每天早上獲取您所在城市的天氣預報，並通過 Telegram 或電子郵件發送通知。

使用節點：Schedule, HTTP Request, Function, Send Email/Telegram

練習 2：網站監控

創建一個工作流，定期檢查指定網站是否可訪問，如果無法訪問則發送警報通知。

使用節點：Schedule, HTTP Request, IF, Send Email/Telegram

練習 3：RSS 訂閱摘要

創建一個工作流，從多個 RSS 源獲取最新文章，合併並發送每日摘要。

使用節點：Schedule, RSS Read, Function, Merge, Send Email

練習 4：文件備份

創建一個工作流，定期將指定文件夾中的文件備份到雲存儲服務（如 Google Drive 或 Dropbox）。

使用節點：Schedule, Read Binary File, Google Drive/Dropbox
