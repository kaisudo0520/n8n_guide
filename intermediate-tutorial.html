n8n 中級教學：進階工作流與整合

本教學將深入探討 n8n 的進階功能和更複雜的工作流設計。適合已經掌握 n8n 基礎知識，希望進一步提升自動化能力的用戶。通過本教學，您將學習如何創建更強大、更靈活的自動化工作流，處理複雜數據，並與各種外部服務進行整合。

進階工作流設計

在基礎教學中，我們學習了如何創建簡單的線性工作流。現在，讓我們探索更複雜的工作流設計技巧。

分支與條件執行

在實際應用中，我們經常需要根據不同條件執行不同的操作。n8n 提供了兩種主要的分支節點：

IF 節點

IF 節點允許您基於條件將工作流分為兩個分支：

  • 條件設置：支持多種比較運算符和邏輯運算符
  • True/False 分支：條件滿足時執行 True 分支，否則執行 False 分支
  • 多條件組合：使用 AND/OR 組合多個條件

示例：根據天氣情況發送不同的通知

// IF 節點條件設置
// 檢查溫度是否高於 30 度
return $input.item.json.temperature > 30;
Switch 節點

當需要多個分支時，Switch 節點比多個 IF 節點更適合：

  • 多分支支持：可以設置多個條件和對應的分支
  • 默認分支：當所有條件都不滿足時執行
  • 靈活的條件表達式：支持複雜的 JavaScript 表達式

示例：根據用戶類型執行不同操作

// Switch 節點條件設置
// 根據用戶類型分類
switch ($input.item.json.userType) {
  case 'admin':
    return 'admin';
  case 'manager':
    return 'manager';
  case 'regular':
    return 'regular';
  default:
    return 'guest';
}

循環與批處理

處理大量數據時，循環和批處理是必不可少的技術。n8n 提供了多種方式來處理數據集合：

Split In Batches 節點

將大型數據集分割為較小的批次進行處理：

  • 批次大小：控制每批處理的項目數量
  • 並行處理：提高處理效率
  • 減輕負載：避免 API 限制和超時

示例：批量處理用戶數據

// Split In Batches 節點設置
// 批次大小：50
// 輸入字段：users
// 選項：並行處理
Loop Over Items 節點

對每個項目執行相同的操作序列：

  • 項目迭代：逐個處理每個項目
  • 子工作流：為每個項目執行一系列操作
  • 結果合併：將所有處理結果合併

示例：為每個產品生成詳細報告

// Loop 節點後的 Function 節點
// 處理每個產品
return items.map(item => {
  const product = item.json;
  
  // 生成詳細報告

    id: product.id,
    name: product.name,
    salesAnalysis: analyzeSales(product.sales),
    performanceMetrics: calculateMetrics(product),
    recommendations: generateRecommendations(product)
  };
  
  return { json: report };
});

數據處理與轉換

數據處理是自動化工作流的核心。n8n 提供了強大的工具來處理和轉換各種格式的數據。

Function 節點進階用法

Function 節點是 n8n 中最靈活的節點之一，可以執行任意 JavaScript 代碼：

複雜數據轉換

使用 JavaScript 進行高級數據轉換：

// 複雜數據轉換示例
return items.map(item => {
  const data = item.json;
  
  // 深度嵌套數據提取
  const extractedData = data.results.map(result => {
    return {
      id: result.id,
      name: result.properties.name,
      value: result.properties.metrics.value,
      category: result.properties.category.main
    };
  });
  
  // 數據聚合
  const aggregated = extractedData.reduce((acc, curr) => {
    if (!acc[curr.category]) {
      acc[curr.category] = {
        count: 0,
        totalValue: 0,
        items: []
      };
    }
    
    acc[curr.category].count += 1;
    acc[curr.category].totalValue += curr.value;
    acc[curr.category].items.push({
      id: curr.id,
      name: curr.name,
      value: curr.value
    });
    
    return acc;
  }, {});
  
  return { json: { aggregated } };
});

XML 處理

處理 XML 數據：

// XML 處理示例
const xml2js = require('xml2js');
const parser = new xml2js.Parser({ explicitArray: false });

return items.map(item => {
  const xmlData = item.json.xmlContent;
  
  // 將 XML 轉換為 JSON
  let jsonData;
  parser.parseString(xmlData, (err, result) => {
    if (err) throw new Error(`XML parsing error: ${err.message}`);
    jsonData = result;
  });
  
  // 處理轉換後的 JSON 數據
  const processed = {
    title: jsonData.rss.channel.title,
    description: jsonData.rss.channel.description,
    items: Array.isArray(jsonData.rss.channel.item) 
      ? jsonData.rss.channel.item 
      : [jsonData.rss.channel.item]
  };
  
  return { json: processed };
});

數據聚合和分析

對數據進行聚合和分析以獲取洞察：

基本聚合

計算總和、平均值、最大值等：

// 基本聚合示例
return items.map(item => {
  const sales = item.json.salesData;
  
  // 計算總銷售額
  const totalSales = sales.reduce((sum, sale) => sum + sale.amount, 0);
  
  // 計算平均銷售額
  const averageSale = totalSales / sales.length;
  
  // 找出最大銷售額
  const maxSale = Math.max(...sales.map(sale => sale.amount));
  
  // 找出最小銷售額
  const minSale = Math.min(...sales.map(sale => sale.amount));
  
  return {
    json: {
      totalSales,
      averageSale,
      maxSale,
      minSale,
      salesCount: sales.length
    }
  };
});
分組聚合

按類別或其他屬性分組聚合數據：

// 分組聚合示例
return items.map(item => {
  const products = item.json.products;
  
  // 按類別分組
  const byCategory = products.reduce((groups, product) => {
    const category = product.category;
    
    if (!groups[category]) {
      groups[category] = {
        count: 0,
        totalValue: 0,
        items: []
      };
    }
    
    groups[category].count += 1;
    groups[category].totalValue += product.price;
    groups[category].items.push(product);
    
    return groups;
  }, {});
  
  // 計算每個類別的平均價格
  Object.keys(byCategory).forEach(category => {
    byCategory[category].averagePrice = 
      byCategory[category].totalValue / byCategory[category].count;
  });
  
  return { json: { categoryAnalysis: byCategory } };
});
時間序列分析

分析時間序列數據：

// 時間序列分析示例
const moment = require('moment');

return items.map(item => {
  const timeData = item.json.timeSeriesData;
  
  // 按日期分組
  const byDate = timeData.reduce((groups, entry) => {
    const date = moment(entry.timestamp).format('YYYY-MM-DD');
    
    if (!groups[date]) {
      groups[date] = {
        count: 0,
        totalValue: 0,
        entries: []
      };
    }
    
    groups[date].count += 1;
    groups[date].totalValue += entry.value;
    groups[date].entries.push(entry);
    
    return groups;
  }, {});
  
  // 計算每日平均值
  const dailyAverages = Object.keys(byDate).map(date => ({
    date,
    average: byDate[date].totalValue / byDate[date].count,
    count: byDate[date].count
  }));
  
  // 按日期排序
  dailyAverages.sort((a, b) => moment(a.date).diff(moment(b.date)));
  
  return { json: { dailyAnalysis: dailyAverages } };
});

// 自定義錯誤處理示例
return items.map(item => {
  try {
    // 嘗試執行可能失敗的操作
    const result = riskyOperation(item.json);
    return { json: { success: true, data: result } };
  } catch (error) {
    // 記錄錯誤
    console.error(`Error processing item ${item.json.id}: ${error.message}`);
    
    // 根據錯誤類型執行不同的處理
    if (error.message.includes('rate limit')) {
      // 速率限制錯誤 - 可以稍後重試
      return { 
        json: { 
          success: false, 
          error: 'rate_limit', 
          retryAfter: 60,
          originalData: item.json 
        } 
      };
    } else if (error.message.includes('not found')) {
      // 資源不存在 - 無需重試
      return { 
        json: { 
          success: false, 
          error: 'not_found',
          originalData: item.json 
        } 
      };
    } else {
      // 其他錯誤
      return { 
        json: { 
          success: false, 
          error: 'unknown',
          message: error.message,
          originalData: item.json 
        } 
      };
    }
  }
});

重試機制和備份策略

實現可靠的重試和備份機制：

自動重試

為不穩定的 API 實現重試邏輯：

// 重試邏輯示例
async function makeRequestWithRetry(url, options, maxRetries = 3, delay = 1000) {
  let lastError;
  
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const response = await fetch(url, options);
      
      if (!response.ok) {
        throw new Error(`HTTP error ${response.status}`);
      }
      
      return await response.json();
    } catch (error) {
      console.error(`Attempt ${attempt} failed: ${error.message}`);
      lastError = error;
      
      // 如果還有重試次數，等待後重試
      if (attempt < maxRetries) {
        console.log(`Waiting ${delay}ms before retry...`);
        await new Promise(resolve => setTimeout(resolve, delay));
        
        // 指數退避策略
        delay *= 2;
      }
    }
  }
  
  throw new Error(`Failed after ${maxRetries} attempts: ${lastError.message}`);
}
數據備份

return items.map(item => {
  const data = item.json;

    ...data,
    _backup: {

    }
  };
  
  // 格式化為 JSON 字符串
  const backupJson = JSON.stringify(backupData, null, 2);

    json: {
      backupData,

    },
    binary: {
      data: {
        data: Buffer.from(backupJson).toString('base64'),
        mimeType: 'application/json'
      }
    }
  };
});

// 緩存策略示例
// Function 節點 - 檢查緩存
return items.map(item => {
  const cacheKey = `data_${item.json.id}`;
  
  // 檢查工作流變量中是否有緩存
  if ($workflow.variables[cacheKey] && 
      $workflow.variables[cacheKey].timestamp > Date.now() - 3600000) {
    // 緩存有效（1小時內）
    console.log(`Cache hit for ${cacheKey}`);
    return {
      json: {
        ...$workflow.variables[cacheKey].data,
        fromCache: true
      }
    };
  } else {
    // 緩存未命中或已過期
    console.log(`Cache miss for ${cacheKey}`);
    return {
      json: {
        ...item.json,
        fromCache: false
      }
    };
  }
});

return items.map(item => {

    // 記錄成功

      itemId: item.json.id,

  }
