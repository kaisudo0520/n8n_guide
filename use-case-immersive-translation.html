實用案例：吳恩達三階段沉浸式翻譯實作

本案例將指導您如何使用 n8n 實現吳恩達（Andrew Ng）提出的三階段沉浸式翻譯方法。這種方法特別適合學習外語和處理專業文獻，能夠在保留原文精確含義的同時，生成流暢自然的譯文。通過 n8n 自動化這一過程，您可以高效處理大量文本，並獲得高質量的翻譯結果。

案例概述

吳恩達三階段沉浸式翻譯方法是一種結合人工智能和語言學原理的翻譯方法，分為三個階段：

  1. 直譯階段：逐字逐句翻譯，保留原文結構
  2. 意譯階段：調整語序和表達，使譯文更符合目標語言習慣
  3. 優化階段：進一步優化譯文，使其更加流暢自然

這種方法特別適合處理專業文獻、學術論文和技術文檔，能夠在保留原文精確含義的同時，生成流暢自然的譯文。

主要功能

  • 自動化三階段翻譯流程
  • 支持多種語言之間的翻譯
  • 處理各種格式的文本（純文本、Markdown、HTML等）
  • 保留原文格式和結構
  • 生成對照版本，方便學習和比較
  • 批量處理多個文件

技術要求

  • n8n 實例（自託管或雲端）
  • OpenAI API 密鑰（用於 GPT 模型）
  • （可選）其他翻譯 API（如 DeepL、Google Translate）
  • （可選）文件存儲服務（如 Google Drive、Dropbox）

工作流架構

我們的自動化工作流將分為四個主要部分：

1. 文本預處理

這部分負責準備待翻譯的文本：

  • 文本輸入：支持多種輸入方式（直接輸入、文件上傳、URL）
  • 格式檢測：識別文本格式（純文本、Markdown、HTML等）
  • 文本分割：將長文本分割為適合翻譯的片段
  • 格式保留：提取和保存需要在翻譯後恢復的格式標記

2. 三階段翻譯

這部分實現核心的三階段翻譯流程：

  • 直譯階段：使用 LLM 或翻譯 API 進行逐字逐句翻譯
  • 意譯階段：調整語序和表達，使譯文更符合目標語言習慣
  • 優化階段：進一步優化譯文，使其更加流暢自然
  • 專業術語處理：確保專業術語的準確翻譯

3. 後處理與格式恢復

這部分處理翻譯後的文本：

  • 格式恢復：恢復原文的格式標記
  • 片段合併：將分割的文本片段重新組合
  • 一致性檢查：確保術語和表達的一致性
  • 對照版本生成：創建原文和譯文的對照版本

4. 輸出與存儲

這部分處理最終的翻譯結果：

  • 多格式輸出：支持多種輸出格式（純文本、Markdown、HTML、PDF等）
  • 文件存儲：將結果保存到本地或雲存儲
  • 通知與分享：通過電子郵件或消息通知用戶，提供分享選項
  • 歷史記錄：保存翻譯歷史，方便後續查詢和使用

1.5 文本分割
// 添加 Merge 節點
// 模式：合併所有

// 添加 Function 節點
// 分割文本為適合翻譯的片段
return items.map(item => {
  const text = item.json.text;
  const format = item.json.format;
  
  // 根據格式選擇分割策略
  let segments = [];
  
  if (format === 'plain') {
    // 純文本按段落分割
    segments = text.split(/\n\s*\n/).filter(s => s.trim().length > 0);
  } else if (format === 'markdown') {
    // Markdown 按標題和段落分割
    // 這是一個簡化的實現，實際應用可能需要更複雜的解析
    const lines = text.split('\n');
    let currentSegment = '';
    
    for (const line of lines) {
      // 如果是標題行或空行，開始新的片段
      if (line.startsWith('#') || line.trim() === '') {
        if (currentSegment.trim().length > 0) {
          segments.push(currentSegment.trim());
          currentSegment = '';
        }
        
        if (line.trim() !== '') {
          segments.push(line);
        }
      } else {
        currentSegment += line + '\n';
      }
    }
    
    // 添加最後一個片段
    if (currentSegment.trim().length > 0) {
      segments.push(currentSegment.trim());
    }
  } else if (format === 'html') {
    // HTML 需要更複雜的處理，這裡使用簡化的方法
    // 實際應用可能需要使用 HTML 解析庫
    segments = text.split(/<\/(p|h1|h2|h3|h4|h5|h6|div|section|article)>/)
                  .filter(s => s.trim().length > 0)
                  .map(s => s + (s.match(/<(p|h1|h2|h3|h4|h5|h6|div|section|article)/) ? '' : '
'));
  }
  
  // 合併過小的片段
  const maxSegmentLength = 1000; // 每個片段的最大字符數
  const consolidatedSegments = [];
  let currentSegment = '';
  
  for (const segment of segments) {
    if (currentSegment.length + segment.length > maxSegmentLength) {
      consolidatedSegments.push(currentSegment);
      currentSegment = segment;
    } else {
      currentSegment += (currentSegment ? '\n\n' : '') + segment;
    }
  }
  
  if (currentSegment) {
    consolidatedSegments.push(currentSegment);
  }
  
  return {
    json: {
      ...item.json,
      segments: consolidatedSegments,
      segmentCount: consolidatedSegments.length
    }
  };
});

// 添加 Function 節點
// 估算令牌數和成本
function estimateTokens(text) {
  // 簡單估算：平均每 4 個字符約 1 個令牌
  return Math.ceil(text.length / 4);
}

function estimateCost(tokens, model) {
  // 簡化的成本估算（美元）
  const rates = {
    'gpt-4': {
      input: 0.00003,
      output: 0.00006
    },
    'gpt-3.5-turbo': {
      input: 0.000001,
      output: 0.000002
    }
  };
  
  const rate = rates[model] || rates['gpt-3.5-turbo'];
  
  // 假設輸出令牌約為輸入的 1.5 倍
  const inputCost = tokens * rate.input;
  const outputCost = tokens * 1.5 * rate.output;
  
  return inputCost + outputCost;
}

return items.map(item => {

2. 長文本處理

問題：處理長文本時可能遇到 API 限制和上下文丟失。

解決方案：

  • 實施更智能的文本分割策略
  • 保持段落和章節的完整性
  • 使用重疊分割，確保上下文連續性
  • 實施段落間的一致性檢查
// 添加 Function 節點
// 智能文本分割
function smartTextSplit(text, maxLength = 1000, overlap = 200) {
  // 如果文本足夠短，直接返回
  if (text.length <= maxLength) {
    return [text];
  }
  
  // 按段落分割
  const paragraphs = text.split(/\n\s*\n/);
  const segments = [];
  let currentSegment = '';
  
  for (const paragraph of paragraphs) {
    // 如果添加這個段落會超出最大長度，先保存當前片段
    if (currentSegment.length + paragraph.length > maxLength && currentSegment.length > 0) {
      segments.push(currentSegment);
      
      // 保留一部分重疊內容
      const lastParagraphs = currentSegment.split(/\n\s*\n/).slice(-2);
      currentSegment = lastParagraphs.join('\n\n');
    }
    
    // 添加當前段落
    currentSegment += (currentSegment ? '\n\n' : '') + paragraph;
  }
  
  // 添加最後一個片段
  if (currentSegment) {
    segments.push(currentSegment);
  }
  
  return segments;
}

return items.map(item => {
  const text = item.json.text;
  const segments = smartTextSplit(text);
  
  return {
    json: {
      ...item.json,
      segments,
      segmentCount: segments.length
    }
  };
});

解決方案：

// 添加 Function 節點
// 格式保護和恢復
function protectFormat(text, format) {
  if (format === 'markdown') {
    // 保護 Markdown 格式
    // 替換 Markdown 標記為佔位符
    let protected = text;
    const markers = [];
    
    // 保護代碼塊
    protected = protected.replace(/```[\s\S]*?```/g, (match) => {
      markers.push({ type: 'code_block', content: match });
      return `[FORMAT_MARKER_${markers.length - 1}]`;
    });
    
    // 保護行內代碼
    protected = protected.replace(/`[^`]*`/g, (match) => {
      markers.push({ type: 'inline_code', content: match });
      return `[FORMAT_MARKER_${markers.length - 1}]`;
    });
    
    // 保護鏈接
    protected = protected.replace(/\[([^\]]+)\]\(([^)]+)\)/g, (match, text, url) => {
      markers.push({ type: 'link', content: match, text, url });
      return `[FORMAT_MARKER_${markers.length - 1}]`;
    });
    
    // 保護圖片
    protected = protected.replace(/!\[([^\]]*)\]\(([^)]+)\)/g, (match, alt, src) => {
      markers.push({ type: 'image', content: match, alt, src });
      return `[FORMAT_MARKER_${markers.length - 1}]`;
    });
    
    return { protected, markers };
  }
  
  // 其他格式的處理...
  
  return { protected: text, markers: [] };
}

function restoreFormat(text, markers) {
  let restored = text;
  
  // 恢復所有標記
  for (let i = 0; i < markers.length; i++) {
    restored = restored.replace(`[FORMAT_MARKER_${i}]`, markers[i].content);
  }
  
  return restored;
}

return items.map(item => {
  const text = item.json.segment;
  const format = item.json.format;
  
  const { protected, markers } = protectFormat(text, format);
  
  return {
    json: {
      ...item.json,
      originalSegment: text,
      protectedSegment: protected,
      formatMarkers: markers
    }
  };
});

4. 專業術語不一致

問題：不同片段中的專業術語可能翻譯不一致。

解決方案：

  • 建立和維護術語表
  • 實施術語一致性檢查
  • 使用術語提取和標準化
  • 添加術語審校步驟
// 添加 Function 節點
// 術語一致性檢查
return items.map(item => {
  const segments = item.json.segments || [];
  const translations = item.json.translations || [];
  
  // 提取所有可能的術語對
  const termPairs = {};
  
  // 從每個片段中提取術語對
  segments.forEach((segment, index) => {
    const translation = translations[index] || '';
    
    // 這裡使用簡化的方法，實際應用可能需要更複雜的術語提取
    const sourceTerms = segment.match(/\b[A-Z][a-z]*(?:\s+[A-Z][a-z]*)*\b/g) || [];
    
    sourceTerms.forEach(term => {
      if (!termPairs[term]) {
        termPairs[term] = new Set();
      }
      
      // 嘗試在翻譯中找到對應術語
      // 這是一個簡化的方法，實際應用需要更準確的術語對齊
      const termRegex = new RegExp(`\\b[^\\s]{${term.length - 2},${term.length + 2}}\\b`, 'g');
      const matches = translation.match(termRegex) || [];
      
      matches.forEach(match => {
        termPairs[term].add(match);
      });
    });
  });
  
  // 檢查術語一致性
  const inconsistentTerms = {};
  
  Object.entries(termPairs).forEach(([sourceTerm, targetTerms]) => {
    if (targetTerms.size > 1) {
      inconsistentTerms[sourceTerm] = Array.from(targetTerms);
    }
  });
  
  return {
    json: {
      ...item.json,
      termPairs,
      inconsistentTerms,
      hasInconsistentTerms: Object.keys(inconsistentTerms).length > 0
    }
  };
});
