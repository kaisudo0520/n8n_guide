實用案例：自動發佈新聞到社群媒體

本案例將指導您如何使用 n8n 創建一個自動化工作流，定期從多個來源收集新聞和文章，進行處理和篩選，然後自動發佈到各種社群媒體平台。這個解決方案特別適合需要保持社群媒體活躍度，但又希望減少手動操作的個人、內容創作者和企業。

案例概述

在當今數位時代，保持社群媒體的活躍度對於個人品牌和企業來說至關重要。然而，持續手動發佈高質量內容既耗時又費力。本案例將展示如何使用 n8n 自動化整個流程，從內容收集到發佈，讓您能夠專注於更有價值的工作。

主要功能

  • 從多個來源（RSS 訂閱、新聞 API、網站爬蟲）自動收集內容
  • 使用關鍵詞和 AI 篩選相關內容
  • 使用 LLM 生成吸引人的社群媒體貼文
  • 自動發佈到多個社群媒體平台（Twitter/X、Facebook、LinkedIn、Instagram）
  • 根據最佳發佈時間安排貼文
  • 追蹤發佈結果和互動數據

技術要求

  • n8n 實例（自託管或雲端）
  • 各社群媒體平台的開發者帳號和 API 密鑰
  • （可選）OpenAI API 密鑰用於內容生成和優化
  • （可選）新聞 API 服務（如 NewsAPI、GDELT）的 API 密鑰

工作流架構

我們的自動化工作流將分為四個主要部分：

1. 內容收集

這部分負責從各種來源收集潛在的內容：

  • RSS 訂閱：從選定的博客、新聞網站和出版物獲取最新文章
  • 新聞 API：使用 NewsAPI、GDELT 等服務獲取特定主題的新聞
  • 網站爬蟲：從不提供 RSS 的特定網站抓取內容
  • 社群媒體監控：追蹤特定主題的熱門討論

2. 內容處理與篩選

這部分處理和篩選收集到的內容：

  • 關鍵詞篩選：根據預定義的關鍵詞和主題篩選內容
  • 重複檢測：避免發佈重複內容
  • 內容評分：使用 AI 評估內容相關性和質量
  • 摘要生成：提取或生成內容摘要

3. 貼文生成

這部分為每個平台生成優化的貼文：

  • 平台特定格式：根據每個平台的特性調整內容格式
  • 標題優化：使用 AI 生成吸引人的標題
  • 圖片處理：獲取或生成適合的配圖
  • 標籤生成：自動生成相關標籤

4. 發佈與監控

這部分處理內容發佈和結果追蹤：

  • 發佈排程：根據最佳時間安排貼文
  • 多平台發佈：同時或依序發佈到多個平台
  • 結果追蹤：收集互動數據（點讚、分享、評論）
  • 報告生成：定期生成效果報告

  '人工智能', 'AI', '機器學習', '深度學習', 
  '自動化', 'n8n', '工作流', 'workflow',
  '數據科學', '大數據', '雲計算'

// 定義排除詞列表
const excludeWords = [
  '廣告', '贊助', '促銷'
];

return items.filter(item => {
  const data = item.json;
  const text = `${data.title} ${data.description} ${data.content}`.toLowerCase();
  
  // 檢查是否包含任何關鍵詞
  const hasKeyword = keywords.some(keyword => 
    text.includes(keyword.toLowerCase())
  );
  
  // 檢查是否包含任何排除詞
  const hasExcludeWord = excludeWords.some(word => 
    text.includes(word.toLowerCase())
  );
  
  // 只保留包含關鍵詞且不包含排除詞的內容
  return hasKeyword && !hasExcludeWord;
});

常見問題與解決方案

實施過程中可能遇到的常見問題及其解決方案：

1. API 限制和速率限制

問題：社群媒體平台的 API 限制可能導致發佈失敗。

解決方案：

  • 實施指數退避重試機制
  • 使用多個 API 密鑰輪換使用
  • 分散發佈時間，避免短時間內大量請求
  • 監控 API 使用情況，在接近限制時暫停操作
// 添加 Function 節點實現重試機制
async function makeRequestWithRetry(url, options, maxRetries = 3, delay = 1000) {
  let lastError;
  
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const response = await fetch(url, options);
      
      if (!response.ok) {
        // 檢查是否是速率限制錯誤
        if (response.status === 429) {
          const retryAfter = parseInt(response.headers.get('Retry-After') || '60');
          console.log(`Rate limited. Waiting ${retryAfter} seconds...`);
          await new Promise(resolve => setTimeout(resolve, retryAfter * 1000));
          continue;
        }
        
        throw new Error(`HTTP error ${response.status}`);
      }
      
      return await response.json();
    } catch (error) {
      console.error(`Attempt ${attempt} failed: ${error.message}`);
      lastError = error;
      
      // 如果還有重試次數，等待後重試
      if (attempt < maxRetries) {
        console.log(`Waiting ${delay}ms before retry...`);
        await new Promise(resolve => setTimeout(resolve, delay));
        
        // 指數退避策略
        delay *= 2;
      }
    }
  }
  
  throw new Error(`Failed after ${maxRetries} attempts: ${lastError.message}`);
}
